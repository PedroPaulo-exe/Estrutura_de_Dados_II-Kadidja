# Estrutura_de_Dados_II-Kadidja
# 📚 Estrutura de Dados II

Repositório destinado às atividades, exercícios e projetos desenvolvidos na disciplina de **Estrutura de Dados II**, sob orientação da professora Kadidja.

## 📂 Conteúdo do repositório

| Pasta | Descrição |
|---|---|
| `Apostilas/` | Materiais de estudo e apostilas da disciplina. |
| `Atividade_Remota/` | Atividades realizadas remotamente. |
| `Busca_Binaria/` | Implementações e exercícios de busca binária. |
| `Estrutura_de_dados_Avaçados/` | Atividades envolvendo estruturas de dados avançadas, incluindo árvores Red-Black. |
| `Grafos/` | Exercícios e atividades relacionados a grafos, incluindo o projeto ConectaUDF. |

## 🎯 Objetivo

Organizar e registrar o desenvolvimento das atividades práticas da disciplina, aplicando os conceitos de estruturas de dados e algoritmos.

## 🛠️ Tecnologias

As linguagens e ferramentas utilizadas variam conforme a atividade desenvolvida.
